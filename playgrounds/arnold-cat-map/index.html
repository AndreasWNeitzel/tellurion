Arnold cat map

Arnold's cat map on the unit torus: x' = (2x + y) mod 1, y' = (x + y) mod 1. The Jacobian [[2, 1], [1, 1]] has determinant 1, so the map is area-preserving and reversible. Its eigenvalues (3 +/- sqrt 5) / 2 are one expanding and one contracting; the max Lyapunov exponent is log((3 + sqrt 5) / 2) = 0.9624. On an N x N pixel grid the map is finite-order; for N = 64 the period is 48 iterations. Watch the initial pattern shred into apparent noise, then recur exactly.
