Runge phenomenon: equispaced vs Chebyshev nodes

What you are seeing: polynomial interpolation of the Runge function f(x)=1/(1+25x2)f(x) = 1 / (1 + 25 x^2)f(x)=1/(1+25x2) on [−1,1][-1, 1][−1,1]. With equispaced nodes (orange), the interpolant matches at the nodes but oscillates wildly between them. With Chebyshev nodes (cyan), it converges uniformly. The black curve is the true function.

Cause: equispaced interpolation has a Lebesgue constant that grows like 2n/n2^n / n2n/n. Chebyshev nodes cluster at the endpoints to keep the constant bounded (O(log⁡n)O(\log n)O(logn)). The bottom panel plots max error vs nnn for both schemes.
