# Eclipse Prediction

Sun-Earth-Moon in 3D with the Moon's 5.145° orbital tilt and an
angular-radius eclipse condition. Scrub the time slider or hit
"Next solar" / "Next lunar" to jump to the next eclipse event. The
headline strip names the condition (SOLAR / LUNAR / no eclipse) and
the readout reports the Sun-Moon angular separation theta.

Engine: closed-form circular ephemeris + angular-separation test
against (Sun + Moon) angular radii. Honest geometry; the bodies are
scaled up for visibility.

Reference: Meeus, Astronomical Algorithms, 2nd ed., Ch. 47 (solar) and
54 (lunar).
