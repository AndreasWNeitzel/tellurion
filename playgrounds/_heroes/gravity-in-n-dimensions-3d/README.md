# Gravity in n Spatial Dimensions

The Bertrand/Ehrenfest stability argument made visual. The planet
orbits a heavy mass under the generalized central force

  F = -k * r / r^d   (for d > 2)
  F = -k * r / r^2   (for d = 2, log potential)

Only d = 3 gives the closed Kepler ellipse Newton found. The slider
sweeps d from 2 (precessing rosette) through 3 (closed) to 4
(marginal, tilts) to 5-6 (plunging spiral into the centre).

This is one classical answer to "why three spatial dimensions": orbits
are only stable there.
