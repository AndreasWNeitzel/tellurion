In-browser physics, astronomy, and machine-learning playgrounds. Every shipped card is gated by a strong physical or analytic invariant plus an SSIM visual gate. See docs/BUILD_ORDER.md for the full plan and docs/INDEX.md for a markdown index.

These playgrounds load playground.js as an ES module, so they cannot be opened directly from file:// in Chromium. Serve the project over HTTP with npm run dev (vite) or any static server.
