Playgrounds portfolio

Canvas2D and SVG physics and ML playgrounds, each verified by a strong physical invariant and a perceptual SSIM gate. See docs/INDEX.md for the public catalog and docs/BUILD_ORDER.md for the build plan.

These playgrounds load playground.js as an ES module from the project's shared engine, so they cannot be opened directly from file:// in Chromium. Serve the project over HTTP with npm run dev (vite) or any static server, then visit the URL.
